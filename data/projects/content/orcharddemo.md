## Orchard Demo Collection (2025)

The Orchard Demo Collection is a collection of smaller applications created to test and showacase Orchard app development.

The collection contains different small applications and experiments, some useful, some less, but the point is to provide examples of how to use the SDK.

The apps show
- SDK usage
- Storage handling
