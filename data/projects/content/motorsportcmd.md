## Motorsport manager CMD game

Perfect example of an experiment project. 

For no particular reason other than my own enjoyment I created a C# console app, where you can manage races for a selected Formula 1 driver on a selected GP circuit.

Game features here (remember, it's all in a console app):
- "Visual" menu and management screen
- .csv database to save settings and grid data
- Qualifing and race simulation with pit stops and dynamic weather (!!!)
- Editable database from inside the app
